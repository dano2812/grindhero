# Architecture decision records

ADRs record durable choices with context and consequences. Use increasing IDs
(`0001`, `0002`, ...); do not rewrite history to hide a superseded decision.
Statuses: Proposed, Accepted, Superseded (link replacement).

Current decisions:

- [ADR-0001: Unity mobile client foundation](0001-unity-mobile-foundation.md)

For a new record use: title, date/status, context, decision, alternatives,
consequences, validation, and revisit trigger. A proposed technology is not
permission to install it.
